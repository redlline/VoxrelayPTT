# VoxRelay — Feature Roadmap

## Legend
- **MVP** — Must-have для первого релиза (3–4 месяца разработки)
- **v1.0** — Следующий этап (2–3 месяца после MVP)
- **v2.0** — Платформенные и расширенные возможности

---

## 1. Аутентификация и управление пользователями

| Фича | Приоритет | Описание |
|------|-----------|----------|
| Регистрация/логин по email + пароль | MVP | JWT-based, bcrypt |
| OAuth2 (Google, Microsoft, GitHub) | v1.0 | SSO для корпоративных клиентов |
| 2FA (TOTP/WebAuthn) | v1.0 | Двухфакторная аутентификация |
| Active Directory / LDAP | v1.0 | Интеграция с корпоративным AD |
| Role-based Access Control (RBAC) | MVP | admin, dispatcher, user, listener |
| Приглашения по ссылке | v1.0 | Self-service onboarding |
| Session management | MVP | Refresh tokens, revoke |

---

## 2. Push-to-Talk (ядро)

| Фича | Приоритет | Описание |
|------|-----------|----------|
| PTT удержанием клавиши (Space) | MVP | Классический режим |
| PTT удержанием кнопки на экране | MVP | Для touch-устройств |
| Переключение каналов | MVP | Выбор активного канала из списка |
| Визуальная индикация: кто говорит | MVP | Аватар, имя, канал — у всех участников |
| Уровень сигнала (audio meter) | v1.0 | Визуализация громкости |
| VOX (Voice Activation) | v1.0 | Голосовая активация с порогом чувствительности |
| Мгновенное соединение (<400ms latency) | MVP | UDP + WebRTC Opus |
| Список онлайн-участников канала | MVP | Real-time presence |
| История переговоров (текст + аудио) | v1.0 | Сохранение записей в S3 + STT |
| "Тихий" режим (listen-only) | MVP | Пользователь без права говорить |
| Emergency-канал (приоритетный) | v1.0 | Автоматическое переключение для критических сообщений |
| Priority Talk (прерывание) | v1.0 | Диспетчер прерывает текущего говорящего |
| Live-трансляция (односторонняя) | v1.0 | Один говорит — тысячи слушают |
| Push-to-Talk в фоне | v2.0 | App в фоне, PTT через гарнитуру/уведомление |

## 3. Каналы и группы

| Фича | Приоритет | Описание |
|------|-----------|----------|
| Создание публичных/приватных каналов | MVP | Постоянные каналы |
| Присоединение по приглашению | MVP | Invite link или код |
| Динамические группы (ad-hoc) | v1.0 | Создание временных групп из онлайн-участников |
| Иерархия каналов (отделы/подразделения) | v1.0 | Древовидная структура |
| Pin-каналы (избранное) | MVP | Быстрый доступ к важным каналам |
| Channel roles (owner, admin, member) | MVP | Права внутри канала |
| Канал с модерацией (raise hand) | v2.0 | Запрос на право говорить |
| Автоматическое распределение по каналам | v2.0 | По LDAP-группе/подразделению |

## 4. Аудио-движок

| Фича | Приоритет | Описание |
|------|-----------|----------|
| Opus codec (8–48 kbps) | MVP | Лучшее соотношение качество/задержка |
| WebRTC с UDP (serverless peer-to-peer) | MVP | Для прямых соединений |
| SFU (Selective Forwarding Unit) | v1.0 | Mediasoup — серверная маршрутизация аудио |
| Адаптивный битрейт (ABR) | v1.0 | Авто-подстройка под качество сети |
| DTX (Discontinuous Transmission) | MVP | Экономия трафика в тишине |
| Comfort Noise Generation (CNG) | MVP | Естественная тишина, без обрывов |
| PLC (Packet Loss Concealment) | MVP | Opus built-in + FEC |
| Шумоподавление (RNNoise) | v1.0 | Нейросетевое подавление шумов |
| Echo cancellation (AEC) | MVP | WebRTC AEC |
| End-to-End шифрование (E2EE) | v2.0 | Signal Protocol / ML-KEM |
| Stereo / multi-channel | v2.0 | Для студийных микрофонов |

## 5. Диспетчерская панель

| Фича | Приоритет | Описание |

| Прослушивание любого канала | MVP | Dispatcher monitor mode |

| Фильтры по подразделениям/группам | v1.0 | Поиск и фильтрация |
| Геопозиция на карте | v2.0 | Leaflet + WebSocket + GPS |
| Журнал переговоров + поиск по STT | v1.0 | Полнотекстовый поиск по расшифровкам |
| Текстовые объявления (broadcast) | v1.0 | Push-уведомления всем/группе |
| Шаблоны сообщений | v2.0 | Заранее заготовленные сообщения |
| Drag-and-drop пользователей в канал | v2.0 | Интерфейс управления |

## Резюме по фазам

| Этап | Длительность | Ключевые фичи |
|------|-------------|----------------|
| **MVP** | 3–4 месяца | PTT через Web, каналы, аутентификация, WebRTC P2P, админка (базовая), Docker |
| **v1.0** | +2–3 месяца | SFU (Mediasoup), запись + STT, диспетчерская панель, VOX, AD/LDAP, мобильные приложения, Tauri desktop, интеграции |
| **v2.0** | +3–4 месяца | E2EE, геолокация, SIP-шлюз, offline, лицензирование, geo-distributed, multi-tenant |
